## 3. Description for Store Listing

### Short Description (<= 80 characters)

> Configure and monitor Soleux Relay, PDU, AC/DC dimmer modules on your local network.

### Full Description (<= 4000 characters)

> **Soleux Device Manager** lets electricians, facility managers, and home automation enthusiasts configure, monitor, and control Soleux hardware modules — all on your local network, with no cloud account required.
>
> **Supported Hardware**
> - **Relay modules** — ON/OFF control for up to 8 outputs per module
> - **Blind/Shutter DC Control** — UP/DOWN/STOP for motorised blinds
> - **DC Lighting Dimmer** — 4 × 12-24V PWM outputs
> - **AC Lighting Dimmer** — 4 × 220V outputs
> - **Temperature modules** — internal module temperature monitoring with configurable thresholds and alerts
>
> **Key Features**
> - **Automatic module discovery** — modules are found on your LAN via UDP broadcast or can be added manually by IP
> - **Live status monitoring** — see module online/offline state, temperature, system info (CPU, memory, uptime)
> - **Full configuration** — name modules, channels, physical inputs; set brightness levels, step sizes, temperature thresholds, input modes (push-button, toggle, momentary, associated)
> - **Scenarios** — create tap-to-run scenes with custom names, icons, colours, and per-channel actions (ON/OFF/brightness/UP/DOWN/STOP). Run them from the Home tab with a single tap
> - **Automations** — set up IF/THEN rules triggered by time schedules or device-state changes
> - **Room/zone organisation** — group modules and scenarios into rooms for easy navigation
> - **30-day event history** — scrollable log of module actions, scenario runs, and automation triggers
> - **Local push notifications** — alerts for module offline/restored, temperature warnings, outputs left on too long, automation events, and firmware updates
> - **Backup & restore** — export/import all configuration to/from a JSON file (stored on your device)
> - **Dark mode & theming** — choose between light, dark, and system themes with custom accent colours
> - **Multi-language** — English and Romanian (more languages coming)
> - **Remote access (opt-in, future)** — MQTT transport infrastructure is built but inactive; future cloud sync will always be opt-in
>
> **Privacy First**
> - **No cloud account required** — everything works entirely on your local network
> - **No analytics, no telemetry, no crash reporting** — your data stays on your device
> - **No data is sent to Soleux or any third party**
> - All data is stored locally (SQLite + key-value store on your device)
>
> **Suitable for:**
> - Electrical contractors and building automation installers
> - Facility maintenance teams
> - Home automation enthusiasts with Soleux hardware
>
> **Note:** This app requires Soleux hardware modules on your local network to function. It is a configuration and monitoring companion, not a standalone utility.

### What's New (for updates)

> Version 1.0.25:
> - Improved module discovery reliability
> - Event history now scrollable with grouped notifications
> - New automation triggers for temperature thresholds
> - Performance improvements and bug fixes
